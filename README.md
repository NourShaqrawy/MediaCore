# Media Core CMS

نظام إدارة محتوى متكامل (CMS) لمؤسسة إعلامية لتبسيط نشر الأخبار وإدارة المقالات بمختلف مجالاتها (سياسة، رياضة، تقنية، إلخ). تم بناء النظام كواجهة برمجية (RESTful API) متطورة باستخدام إطار العمل NestJS، مع قاعدة بيانات PostgreSQL معتمدة على تقنية Prisma ORM.

## مميزات النظام 🎯

- **نظام مصادقة متين (Auth):** تسجيل الدخول والخروج باستخدام `JWT` مع تشفير كلمات المرور باستخدام `bcrypt`.
- **التحكم بالصلاحيات بناءً على الأدوار (RBAC):** توجيه وإدارة سريان العمل بناءً على 3 أدوار رئيسية (Admin, Editor, Writer).
- **إدارة المستخدمين:** لوحة تحكم خلفية للأدمن تتيح له تعطيل، تفعيل أو حذف المستخدمين، مع تغيير أدوارهم.
- **إدارة مقالات منظمة:**
  - يكتب الكاتب مقالته وتبقى كـ (`Draft`).
  - يقدمها الكاتب للمراجعة لتصبح (`Pending`).
  - يقوم المحرر بمراجعتها ومن ثم الموافقة عليها ليتم نشرها (`Published`) أو رفضها (`Rejected`).
- **إدارة التصنيفات (Categories):** ترتيب المقالات ضمن أقسام معرفة مسبقًا ومُدارة بالكامل من قِبَل الإدارة.

## الصلاحيات 🛡️

1. **المدير (Admin):** صلاحيات مطلقة؛ إدارة مستخدمين، إدارة الأقسام، التحكم بالمقالات، حذف ناعم للمقالات، مراجعة ونشر.
2. **المحرر (Editor):** تدقيق المقالات، تغيير الحالة (مقبول / مرفوض)، أو تعديل المحتوى إملائياً.
3. **الكاتب (Writer):** إنشاء المقالات (مسودات)، تعديل مقالاته الخاصة فقط، طلب نشرها.

## التقنيات المستخدمة 🛠️

- **الإطار البرمجي:** [NestJS](https://nestjs.com/) (Node.js)
- **لغة البرمجة:** [TypeScript](https://www.typescriptlang.org/)
- **قاعدة البيانات:** PostgreSQL
- **الـ ORM:** [Prisma](https://www.prisma.io/)
- **المصادقة:** JWT & Passport

## متطلبات التشغيل 📦

- Node.js (v16 أو أحدث).
- قاعدة بيانات PostgreSQL مهيئة وتعمل محليًا أو على خادم.
- مدير حزم (`npm` أو `yarn`).

## التثبيت والاستخدام 🚀

1. **تثبيت الاعتمادات:**
   ```bash
   npm install
   ```

2. **إعداد متغيرات البيئة:**
   قم بإنشاء ملف `.env` في المجلد الرئيسي (انسخ المتغيرات من ملفك الحالي، أو استرشد بالتالي):
   ```env
   DATABASE_URL="postgresql://user:password@localhost:5432/media_core_db"
   JWT_SECRET="your-strong-secret-key"
   JWT_EXPIRES_IN="1d"
   
   ADMIN_EMAIL="admin@media-core.com"
   ADMIN_PASSWORD="SuperSecretPassword123!"
   ADMIN_USERNAME="superadmin"
   ADMIN_FULLNAME="Super Administrator"
   ```

3. **إعداد قاعدة البيانات والأدوار الافتراضية:**
   سيقوم الأمر التالي بتهيئة قاعدة البيانات وإنشاء الأدوات والمستخدم الإداري الافتراضي وتصنيفات المقالات:
   ```bash
   npx prisma migrate reset --force
   ```

4. **تشغيل خادم التطوير:**
   ```bash
   npm run start:dev
   ```

## نقاط النهاية الأساسية (API Endpoints) 📌

### 🔐 المصادقة والـ Auth (`/auth`)
* `POST /auth/register`: إنشاء مستخدم جديد (متاح مبدئياً للمشرفين لتقييد التسجيل).
* `POST /auth/login`: تسجيل الدخول (إرجاع JWT Token).

### 👥 المستخدمين (`/users`) - *محمي بصلاحيات أدمن*
* `GET /users`: عرض كل المستخدمين في النظام.
* `GET /users/:id`: عرض بيانات مستخدم معين.
* `PATCH /users/:id`: تعديل بيانات وصلاحية/تفعيل مستخدم معين.
* `DELETE /users/:id`: إزالة مستخدم من النظام.

### 📚 التصنيفات (`/categories`)
* `GET /categories`: عرض كل الأقسام (الكل).
* `POST /categories`: إضافة قسم جديد (أدمن).
* `PATCH /categories/:id`: تحديث بيانات قسم (أدمن).
* `DELETE /categories/:id`: مسح قسم غير مرتبط بمقالات (أدمن).

### 📰 المقالات (`/articles`)
* `GET /articles`: عرض الأخبار/المقالات متضمنة مرشحات الحالة.
* `POST /articles`: كتابة وبداية مقال جديد كمسودة - Draft (للكُتّاب).
* `PATCH /articles/:id`: حرية التعديل (الكاتب لمقالاته في وضع المسودة، والأدمن أو المحرر لأغراض التدقيق).
* `POST /articles/:id/submit`: توجيه ونقل المقال للمطالبة بالنشر - Pending (للكاتب فقط).
* `POST /articles/:id/review`: قبول/نشر المقال أو رفضه (محرر وأدمن).
* `DELETE /articles/:id`: إخفاء/حذف مقال باستخدام (Soft Delete) - (أدمن).
